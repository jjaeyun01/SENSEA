# 카메라 보조 기능의 구현 범위와 자료 사용

## 이번 변경의 출처

SENSEA 요구사항에 맞춰 사진 품질 검사와 최신 촬영 요청 처리를 새로 작성했습니다. 이미지 히스토그램·에지 강도, 요청 식별자, 취소 신호, 비동기 작업의 세대 비교라는 일반적인 기법을 사용합니다.

이번 변경에는 다른 비공개 프로젝트의 소스 코드, 고유 클래스·설정, 학습 데이터, 사진, 모델 가중치, 내부 문서 또는 실행 파일을 포함하지 않았습니다. 회사 작업 디렉터리를 수정하거나 그 프로젝트에 의존성을 연결하지 않았습니다. 관련 비공개 프로젝트의 경로·실험 결과도 공개 저장소에 옮기지 않았습니다.

품질 검사는 기존 의존성인 Pillow와 자체 규칙으로 구현했고 새로운 사전 학습 모델을 들이지 않았습니다. 테스트 이미지는 코드로 생성한 도형·단색 픽셀입니다. 이후 외부 코드·데이터·가중치를 추가할 때는 각각의 공개 여부와 이용·재배포 조건을 확인해야 합니다.

공개 API 참고 자료:

- [Pillow ImageFilter](https://pillow.readthedocs.io/en/stable/reference/ImageFilter.html): 에지 필터 API.
- [Pillow ImageStat](https://pillow.readthedocs.io/en/stable/reference/ImageStat.html): 픽셀 통계 API.
- [Expo Speech](https://docs.expo.dev/versions/latest/sdk/speech/): 음성 시작·중지 인터페이스.

위 문서는 API 사용을 확인하기 위한 자료이며, 비공개 구현을 공개 코드로 옮기기 위한 근거로 사용하지 않습니다.

## 1. 사진 품질 검사

`backend/app/quality.py`는 EXIF 제거와 해상도 제한을 마친 JPEG를 검사합니다. 현재 기본값은 임시 규칙입니다.

| 검사 | 기본 규칙 | 응답 이유 |
| --- | --- | --- |
| 작은 해상도 | 정규화된 이미지의 짧은 변 192px 미만 | low_resolution |
| 어두움 | 검사 영상의 85% 이상이 회색조 값 0~24 | too_dark |
| 과다 노출 | 검사 영상의 85% 이상이 회색조 값 240~255 | too_bright |
| 세부 정보 부족 | 긴 변 최대 512px에서 FIND_EDGES 평균이 1.5 미만 | low_detail |

회색조 변환은 품질 검사에만 사용합니다. 모델에는 원래 색을 유지한 정규화 JPEG를 전달합니다. 에지 필터의 테두리는 통계에서 제외합니다. 큰 해상도를 임의로 늘려 검사에 통과시키지 않습니다.

`low_detail`은 초점 불량 확정이 아닙니다. 단색 벽·하늘처럼 원래 질감이 적은 장면도 해당할 수 있습니다. 반대로 노이즈가 있는 사진은 에지 검사를 통과할 수 있습니다. 모든 흔들림이나 읽기 어려운 글씨를 검출하는 규칙은 아닙니다. 통과는 장면 인식의 정확도나 보행 안전을 보장하지 않습니다.

재촬영 응답은 HTTP 200 / `status=retake`이며 장면 설명·차도·인도 필드를 만들지 않고 공급자 호출도 하지 않습니다. 재촬영 요청도 프로세스의 분당 요청 예산에 포함됩니다. 정지 확인·파일 검증·인증은 그대로 적용합니다.

## 2. 최신 촬영 요청과 음성 출력

촬영 버튼 시점에 요청 세대를 바꾸므로, 예전 카메라 촬영 자체가 늦게 끝나는 경우에도 최신 사진으로 오인하지 않습니다. 서버에 새로운 UUID를 보내고 응답의 동일성을 확인합니다. 응답을 받았을 때와 실제 음성을 큐에 넣기 직전에 세대·정지 상태·유효 시간을 다시 검사합니다.

새 요청, 이동 재개, 화면 종료는 진행 중인 요청을 무효화하고 음성 중지를 예약합니다. 비동기 음성 중지는 직렬 처리해 늦게 끝난 예전 중지가 새 발화를 끊지 않게 합니다. HTTP 취소의 성공 여부와 관계없이 오래된 결과는 앱에 전달하지 않습니다.

이 기능은 `mobile/vision` 연결 모듈입니다. 실제 Expo 화면에 연결되지 않았으므로 휴대폰에서 기능이 동작한다고 간주할 수 없습니다. 서버의 `request_id`만 사용하고 연결 모듈을 생략하면 오래된 음성을 막을 수 없습니다.

## 평가할 다음 항목

본인 촬영 또는 사용 동의를 받은 스마트폰 사진으로 밝은 실외·실내·야간·역광·단색 벽·작은 표지판·흔들림 조건을 평가합니다. 같은 촬영 세션의 사진이 조정용과 평가용에 함께 들어가지 않도록 세션별로 나눕니다. 불필요한 재촬영 비율과 읽기 어려운 사진의 통과 비율을 함께 기록해 임계값을 조정합니다.

실기기에서는 빠른 연속 입력, 네트워크 지연, 백그라운드 전환, 화면 재진입, 이동 재개 시 오래된 음성이 시작되지 않는지 확인합니다. 실제 장면 설명 공급자와 기기 TTS를 연결한 지연·접근성 검증은 아직 수행하지 않았습니다.

## 실시간 입력 확장

추가로 [실시간 프레임 처리](realtime-camera.md)를 구현했습니다. 분석 중 1장과 최신 대기 1장만 보관하며 밝기 버퍼 검사와 자원 해제를 새 코드로 작성했습니다. 기존 비공개 프로젝트에 대한 의존성이나 자료를 추가하지 않았습니다.
