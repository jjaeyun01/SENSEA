# 캠퍼스 보행 경로 순위 정책

## 현재 동작

모바일 앱은 서버가 반환한 Google `WALK` 후보를 `mobile/src/navigation/routeRanking.mjs`로 정렬합니다. 현재는 Google 후보의 보행 시간과, 충분히 관측된 경우에만 크라우드소싱 상대 소음값을 사용합니다. 경사·계단·조명·공사 정보는 아직 경로별 검증 데이터가 없으므로 **미확인**으로 취급합니다. 순위는 보행 안전 또는 범죄 예방을 보증하지 않습니다.

1. 현장 조사로 폐쇄가 확인된 경로는 후보에서 제외합니다. 전부 제외되면 경로가 없다고 알립니다.
2. 가장 빠른 후보보다 25% 또는 5분 넘게 오래 걸리는 우회는 소음·조명 점수만으로 추천하지 않습니다.
3. 낮에는 현장 확인된 장애물·보차 혼용·보호되지 않은 횡단·계단·급경사·중간 경사·비포장 구간에 비용을 부과합니다. 시각장애인에게 장애물이 적다는 주장은 경사 자료만으로 하지 않습니다.
4. 밤에는 같은 보행 조건을 먼저 적용하고, 검증된 조명 구간을 선호합니다. 소음은 경로의 70% 이상에 최근 격자 자료가 있고 측정치 10개 이상, 한 격자에서 기여자 3명 이상일 때만 작은 보조 점수로 사용합니다. 소음은 사람의 존재 또는 범죄 위험을 증명하지 않습니다.
5. 검증 자료가 없으면 짧은 Google 보행 경로가 기본값입니다. 확인되지 않은 구간에 `안전`, `조명 있음`, `계단 없음` 같은 라벨을 붙이지 않습니다.

현재 낮/밤 구분은 계정의 시간대와 낮·밤 시작 시각을 사용합니다. 실제 일몰 시각 기반 전환은 아직 연결되지 않았습니다. 경로 이탈 후 재탐색에도 같은 순위 함수를 사용합니다.

## 필요한 캠퍼스 데이터

[UW 접근 가능 보행로 지도](https://map.wisc.edu/accessible-pedestrian-routes.pdf)의 범례는 0–6% 완만한 **비포장**, 6–9% 중간 경사 **포장**, 9% 초과 가파른 **포장** 구간을 구분합니다. 이 PDF는 경로 구간의 기계 판독 가능한 좌표나 현재 공사·조명 상태를 주지 않습니다. 색 선을 화면에서 추측해 Google 폴리라인에 붙이지 마세요. UW에서 좌표·사용 허가를 받은 자료나 현장 조사로 구간별 다음 값을 확보해야 합니다.

| 값 | 필수 출처·검증 |
| --- | --- |
| 중심선, 연결 노드, 길이 | UW GIS 자료 또는 현장 보행 조사; 일방통행·진입 불가 경계 확인 |
| 포장, 경사 범주, 계단·경사로·횡단보도 | UW 지도와 현장 검증 일시를 함께 기록 |
| 고정 장애물·보차 혼용 구간·횡단 보호 여부 | 현장 보행 조사; 카메라가 그때 탐지한 일반 객체를 영구 지도 자료로 취급하지 않음 |
| 공사·폐쇄 | 공식 공지와 유효 시작·종료 시각; 만료되면 미확인으로 복귀 |
| 가로등·야간 조도 | UW 시설 관리 자료 또는 야간 현장 조사; 설치 위치만으로 실제 점등을 가정하지 않음 |
| 출입구 | 별도의 현장 조사 좌표·오차·일시·설명; `backend/data/entrances.json` 계약 사용 |

구간이 확보되면 서버가 지도 후보와 검증된 중심선을 대조하여 **일치하는 부분만** 경로별 `conditions`로 집계해야 합니다. 인접한 평행 보도나 건물 내부를 잘못 매칭하지 않도록 현장 경로 재생으로 확인하고, 커버되지 않은 길이는 미확인으로 남겨야 합니다. 현재 서버는 `conditions`를 반환하지 않으므로 경사·조명 가중치는 아직 실제 경로에 영향을 주지 않습니다.

## Google 데이터 사용 경계

Google Routes API는 보행 후보와 최대 세 개의 대안을 반환할 수 있지만 보도·보행로가 누락될 수 있다고 명시합니다. 앱에는 Google 경고문과 출처를 유지해야 합니다. Google 지도 앱의 **Terrain** 화면은 시각화이고, 보행 경사도·가로등·실시간 장애물 API가 아닙니다. Elevation API는 지형 고도를 샘플링하지만 응답 해상도 때문에 좁은 보도나 짧은 경사로의 현장 조사 자료로 대체할 수 없습니다.

Google 콘텐츠의 저장·파생 데이터 생성·TTS 사용에는 현재 Maps Platform 약관상 제한이 있으므로, Google 경로 지시문을 음성 안내에 사용하는 현행 방식과 UW PDF의 디지털화 권한은 배포 전에 별도 검토가 필요합니다. 검증된 캠퍼스 독립 경로망을 구축하면 경사·조명 순위와 음성 지시문을 독립 자료에서 생성할 수 있습니다.
