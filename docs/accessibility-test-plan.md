# 접근성 테스트 계획

## 필수 수동 테스트

- iOS VoiceOver와 Android TalkBack에서 화면 요소의 읽기 순서가 시각 순서와 일치한다.
- 모든 버튼이 역할, 이름, 동작 힌트를 제공한다.
- 글자 크기를 200%로 확대해도 목적지 입력과 핵심 버튼을 사용할 수 있다.
- 외부 키보드의 Tab/Enter만으로 주요 흐름을 완료할 수 있다.
- 화면 색상을 보지 않아도 선택 상태, 경고와 오류를 이해할 수 있다.
- TTS와 스크린 리더가 동시에 같은 문장을 말하지 않는다.
- 일시 정지, 반복, 뒤로 가기 후 음성이 겹치지 않는다.
- 카메라와 위치 권한을 거절해도 앱이 종료되지 않고 대체 설명을 제공한다.
- 서버가 꺼진 상태에서 데모 경로로 전환되고 그 사실을 음성으로 알린다.

## 현장 테스트 안전 원칙

- 참가자의 명시적 동의를 받는다.
- 초기 테스트는 실내 또는 차량이 없는 통제 구역에서 진행한다.
- 눈을 가린 비장애인 테스트를 실제 교통 환경에서 수행하지 않는다.
- 참가자가 평소 사용하는 흰지팡이, 안내견 또는 보조 인력을 제한하지 않는다.
- 카메라 설명을 횡단 판단이나 충돌 방지 근거로 사용하지 않는다.
- 실패, 오탐지, 위치 오차를 기록하되 참가자 개인 영상·음성은 기본적으로 저장하지 않는다.
