# 실기기·접근성·현장 검토 계획

아래 항목은 미실시입니다. 코드/빌드 검사가 통과해도 자동으로 완료 표시하지 않습니다. 먼저 정지한 실내 환경에서 시험합니다.

## 기록 양식

- 날짜 / 시험자 역할 / 앱 버전·커밋:
- 기종 / OS / 화면 읽기 버전 / 글자 크기:
- 수행한 작업 / 기대 결과 / 실제 결과 / 재현 순서:
- 지연·오류·발열·메모리 관찰 / 수정 필요사항:

사진·음성·개인 이동 경로를 기록 양식에 첨부하지 않습니다. 참여자 이름 대신 임의 식별자를 사용하고, 피드백의 기록·공유 여부는 사전에 별도로 동의받습니다.

## 권한·중지·개인정보

- [ ] 첫 안내를 취소하면 카메라 권한을 요청하거나 카메라를 켜지 않는다.
- [ ] 카메라 권한 거절·영구 거절·설정에서 철회 후 안내가 이해된다.
- [ ] 끄기·결과 지우기·안내 열기·홈 화면 이동·화면 잠금 시 카메라/음성이 중지된다.
- [ ] 통화/다른 앱의 카메라 점유 후 오류를 알리고 자동으로 재시작하지 않는다.
- [ ] 비행기 모드에서도 모델을 포함한 APK의 로컬 분석이 동작한다.
- [ ] 앱 저장소와 네트워크를 검사해 원본 파일/영상 업로드가 없는지 확인한다.

## TalkBack·VoiceOver

- [ ] 첫 안내 제목부터 시작·중지·다시 듣기·닫기까지 논리적 순서로 탐색된다.
- [ ] 모달 안에서 초점을 이동하고 뒤로가기/접근성 탈출 제스처로 닫을 수 있다.
- [ ] 모달을 닫으면 열었던 버튼으로 초점이 돌아간다.
- [ ] 화면 읽기를 켜고/끄는 중에도 자동 TTS가 겹치지 않는다.
- [ ] 다시 듣기는 최신 결과만 읽고 오래된 결과는 읽지 않는다.
- [ ] 최대 글자 크기에서 텍스트와 버튼이 잘리지 않고 스크롤할 수 있다.
- [ ] 자동 음성을 꺼도 수동 다시 듣기가 동작한다. iPhone 무음 스위치도 확인한다.

## 장시간 카메라

- [ ] 카메라 50회 켜기/끄기, 안내 모달 50회 열기/닫기.
- [ ] 20분 연속 분석에서 메모리·스레드·배터리·온도·결과 지연을 측정한다.
- [ ] 어두움·과다 노출·렌즈 가림·초점 저하·모델 미인식에서 문구가 안전을 단정하지 않는다.
- [ ] 저성능 Android와 iPhone 각각에서 반복한다.

## 이후 서버 사진 화면을 연결할 때

- [ ] 동의 전 사진 생성·네트워크 전송이 없다.
- [ ] 동의 철회·응답 지연·네트워크 끊김·화면 종료 시 늦은 음성이 없다.
- [ ] 성공/실패/취소 뒤 임시 사진이 삭제되고 삭제 실패가 표시된다.
- [ ] HTTPS 리디렉션을 거부하며 토큰·사진이 다른 호스트로 이동하지 않는다.

## 실제 경로·사용자 피드백

- [ ] 현장 조사자가 구간·입구·역방향 안내·검증 시각을 직접 기록한다.
- [ ] 계단·공사·횡단 등 관찰 내용과 보행 구간 연결을 재확인한다.
- [ ] 만료·미검증 구간을 실경로로 반환하지 않는지 확인한다.
- [ ] 시각장애인/저시력 사용자 또는 접근성 전문가가 안내 이해도·음성 속도·오류 회복을 검토한다.
- [ ] 피드백 반영 뒤 같은 작업을 다시 수행해 개선 여부를 확인한다.

실제 이동 시험은 별도 준비가 필요하며 이 시험판의 카메라 결과로 횡단이나 충돌 회피를 판단하지 않습니다. 눈가림 개발자 시험을 당사자 피드백으로 대체하지 않습니다.
